      Ahora entras escribiendo tu correo. Puedes crear un usuario corto con los mismos permisos de administrador y entrar con él. Tu correo sigue funcionando: guárdalo por si olvidas la contraseña nueva.

        Hazlo con internet. Si tu tablet tiene una app de limpieza o ahorro de batería, dale permiso para que no borre los datos de esta app.

        💳 Créditos

        🔒 Estos ajustes los define el administrador y valen para todo el equipo.

        Atajos de vencimiento rápido Dos botones en el formulario para poner el vencimiento X días después de la fecha de despacho.

        🧮 Cabecera de la nota de venta

        Esto es lo que se imprime arriba en cada nota de venta.

        🔔 Notificaciones

        📊 Dashboard

        El Dashboard (resumen del negocio, montos y gráficos) siempre lo ve el administrador. Actívalo aquí si quieres que tus empleados también lo puedan ver.

        🧾 Hoja de cobranza

        Apertura automática: cuando está activa, la hoja de cobranza del día se abre sola para todo el equipo (administrador y empleados) los días y a la hora que elijas. Nadie necesita crearla a mano.
        Días

        🔒 Seguridad

        Código de 4 dígitos que se pedirá para borrar un crédito, borrar una “a cuenta”, anular un movimiento de almacén, editar o borrar un producto, eliminar una nota de venta y reabrir una hoja de cobranza cerrada.

        💾 Respaldo de datos

        Exporta un archivo con todos tus créditos (incluye fotos) para guardarlo o pasarlo a otro dispositivo.
